# Common mistakes

Each row pairs a past failure with the behaviour that replaces it.

| Mistake | Correction |
|---|---|
| Treating a regulator page as authoritative evidence | Government-operated sources are excluded; use qualifying independent evidence. |
| Treating a consumer AI app as an AI Tool | Require a direct use in building, integrating, deploying, evaluating, or operating AI agents. |
| Letting one selection reduce another | Select five to seven AI Tools and three to five Other AI Stories independently of each other and of follow-ups. |
| Filing an employer's AI stance under business and industry | Employee AI-use stances belong in `AI at Work`, one organization and one stance per story. |
| Treating a survey of employers as an AI at Work story | Require a named organization changing its own employees' AI use inside the window. |
| Reading a vendor's adoption case study as a stance change | Vendor-authored adoption marketing is excluded; use the employer's own memo or independent reporting. |
| Printing an empty `AI at Work` heading | Omit the heading entirely when no organization qualifies. |
| Dropping an active mark when no update exists | Keep it in `Tracked Interests` with the exact no-update status. |
| Restarting a mark's clock after a qualifying follow-up | Expiry is absolute: one calendar month from the edition that carried the mark. |
| Copying a checkbox into a follow-up | Only the original new-story block owns the checkbox. |
| Deleting an old marked edition | Preserve it; the archive keeps every edition that carries a mark. |
| Using an article's date for an older event | Verify and use the underlying event date. |
| Skipping a standing topic when the week looks quiet | Query every standing topic every edition and report the ones that found nothing. |
| Adding weak Chinese coverage for symmetry | Keep only sources that improve evidence or context. |
| Leaving a common technical word in English inside Chinese prose, such as `allowlist` | Names stay English; vocabulary translates — write `白名单`. |
| Translating a product or protocol name, such as `智能体技能` for `Agent Skills` | Keep the name in its source capitalization and inflect the Chinese around it. |
| Packing a week of news into one sentence | One idea per sentence; 40 words is the hard cap and the edition averages under 25. |
| Growing one Chinese sentence to cover several English ones | Split the English first, then translate one sentence to one sentence. |
| Shortening a sentence by dropping articles or auxiliaries | Cut an idea instead; STE keeps the grammar intact. |
| Returning only a saved path | Return the clickable path plus the cleanup result, expired marks, and a headline-and-date digest. |
| Pasting the whole edition inline unasked | The link is the deliverable; paste the full Markdown only on request, once. |
| Running independent searches one at a time | Batch mark queries, standing-topic queries, bucket queries, and feed sweeps concurrently; only source checks and scoring serialize. |
| Opening a page to learn a date the snippet already ruled out | Screen on the snippet or URL date first and record a snippet-level rejection. |
| Trusting an aggregator's date or attribution | Re-derive both from the primary source; aggregators are discovery aids. |
| Emailing the edition by default | Email is opt-in; send only when this run's request asks for it. |
| Composing an email body before checking the connector | Confirm the connector exists, then compose. |
